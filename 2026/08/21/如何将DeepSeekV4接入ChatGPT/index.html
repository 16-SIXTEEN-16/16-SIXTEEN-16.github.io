如何将DeepSeekV4接入ChatGPT

安装下载

下载ChatGPT安装后不要进行登录，如已登录退出并关闭后台

下载CC Switch

获取并使用DeepSeek API keys

进入DeepSeek 开放平台点击创建APIkey。！！请务必复制保留显示的key

进入CC Switch确定当前选择是ChatGPT后点击橙色添加新供应商，选择DeepSeek

填写刚才获取到的key，进行测速查看是否成功，后续选项根据自己的选择或默认即可。

使用ChatGPT

打开ChatGPT就可以正常使用了，如已登录请退出并关闭GPT后台重新打开。

模型也显示的是DeepSeek V4，并可以选择使用Pro或者Flash。

本文使用DeepSeek自动上传
